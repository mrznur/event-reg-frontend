# Credits

## Project

**BUCC Event Registration System** — frontend built for the BRAC University Computer Club.

---

## Libraries

| Library | Purpose |
|---|---|
| [Next.js](https://nextjs.org) | React framework (App Router) |
| [Tailwind CSS](https://tailwindcss.com) | Utility-first CSS |
| [Embla Carousel](https://www.embla-carousel.com) | Event and member photo carousels |
| [Lucide React](https://lucide.dev) | Icons |
| [Zod](https://zod.dev) | Form validation |
| [qrcode](https://github.com/soldair/node-qrcode) | QR code generation for tickets |
| [qr-scanner](https://github.com/nimiq/qr-scanner) | Camera-based QR code scanning for check-in |
| [Geist](https://vercel.com/font) | Sans and mono typefaces |

UI design and implementation by the BUCC development team.
